1. WHY THIS FILE EXISTS
----------------------------------------------------------------
Claude has a weekly / daily token allowance. When it hits 90%, work stops until
the allowance resets. To stop that from blocking Olivier, the standing protocol is:

  At 90% of the daily or weekly allowance - or the moment an 'Approaching weekly
  limit' banner appears - Claude must:
    (1) push the latest code to ALL repos, and
    (2) write / refresh HANDOFF.txt at the root of every touched repo, plus
        refresh this master file,
  so that ANY other AI (ChatGPT, Gemini, Copilot, another Claude) can pick the
  work up with zero context from Olivier.

THIS FILE IS THE PICKUP POINT. Start here, then open the HANDOFF.txt inside
whichever repo you are asked to work on.

2. HOW TO WORK WITH OLIVIER - READ BEFORE ANYTHING ELSE
----------------------------------------------------------------
* He is a NON-TECHNICAL founder acting as CTO. He decides; the AI executes.
* He has NO terminal, NO CLI, NO git, NO PowerShell. Never hand him a command,
  a script, a .bat file, or a 'just run this' step. That is a hard failure.
* He does NOT upload, download, move or save files, and does not click buttons
  an AI injected. If an artifact must reach a repo or a host, the AI finds the
  route and executes it.
* Reply format on any actionable request:
    GREEN CHECK = done and ready for him to test, plus the link
    RED CROSS   = still something to do, plus EXACTLY 3 options, all of which he
                  can personally action (an AI does it / a dashboard click /
                  delegate to Charles or Ariel). Never offer a CLI option.
* The same GREEN/RED marker convention applies to every task written into a
  status file or handoff, not just chat replies.
* Executors:  Ariel = code and repository work.
              Charles = Chrome extension + web admin panels (Cloudflare, GitHub
              settings and secrets, DNS, publishing).
* He wants to be alerted by VOICE, not silent popups.
